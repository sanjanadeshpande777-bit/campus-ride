# Campus Ride 🚗

A student-only ride-sharing platform connecting students from NMIT and MIT.

## Problem Statement
Students travelling between campuses and nearby locations often face difficulties finding people to share auto or cab rides with.

## Solution
Campus Ride helps students connect with others travelling in the same direction and share transportation costs.

## Tech Stack
- HTML
- CSS
- JavaScript
- React.js
- Supabase
- PostgreSQL

## Key Features
- Student Registration and Login
- Create a Ride
- Join an Existing Ride
- View Available Rides
- Fare Sharing
- Manage My Rides
